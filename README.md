# Gym Website (Frontend Project)

A modern, responsive, and visually engaging **Gym & Fitness Website** built entirely with core front-end technologies (**HTML5, CSS3, and JavaScript**). This project showcases clean UI design, smooth animations, and an intuitive user experience tailored for fitness centers and personal trainers.

## ✨ Features
*   **Fully Responsive Design:** Optimized for desktops, tablets, and mobile screens.
*   **Interactive UI:** Dynamic navigation menu, smooth scrolling, and animated transitions.
*   **Core Sections:** 
    *   **Hero Section:** High-impact call-to-action (CTA) to grab user attention.
    *   **Membership Plans:** Clean pricing tables comparing different gym tiers.
    *   **Class Schedules:** A structured layout showing available workout routines.
    *   **Trainer Profiles:** Cards introducing fitness coaches and their specialties.
    *   **Contact Form:** A functional, validated front-end form for user inquiries.

## 🛠️ Tech Stack
*   **HTML5:** Structured semantic markup.
*   **CSS3:** Custom layouts (Flexbox/Grid), typography, and smooth transitions.
*   **JavaScript (ES6+):** Dom manipulation, form validation, and interactive UI components.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/sagarpatil-17/gym_website.git
cd YOUR-REPOS-NAME
```

### 2. Run the project
Simply open the `index.html` file directly in any modern browser, or use a development server like **Live Server** in VS Code for live-reloading.
